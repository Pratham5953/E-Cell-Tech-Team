# From Idea to Impact - E-Cell Event Page

A responsive landing page for E-Cell BITS Hyderabad's "From Idea to Impact" event, built for the Tech Team induction task.

## What's inside

- `index.html` - main event page (hero, journey stages, schedule, speakers, etc.)
- `style.css` - dark theme styling
- `script.js` - mobile menu + schedule tab switching
- `registration.html` - registration form
- `registration-style.css` - form styling
- `registration-script.js` - form validation

## How to run

[Click here on the link](https://pratham5953.github.io/E-Cell-Tech-Team/) or just open `index.html` in your browser from the files


## Notes

The information about the speakers can be obtained through Linkedin by clicking on the cards. Form doesn't connect to a backend - it's frontend validation only.
